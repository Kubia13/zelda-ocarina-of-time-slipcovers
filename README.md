# Zelda: Ocarina of Time Slipcovers

Ten printable slipcovers for a Nintendo Switch 2 game case. The project began with the Canadian promotional slipcover and resale listings asking up to about €150. It grew to include North American and European designs inspired by the original Nintendo 64 packaging.

## Download

- [Complete v1.0 ZIP](https://github.com/Kubia13/zelda-ocarina-of-time-slipcovers/releases/download/v1.0/Zelda_Ocarina_of_Time_Slipcovers_Complete.zip)
- [Original print manual · Anleitung-Manual.pdf](./Anleitung-Manual.pdf)

The ZIP includes the SVG masters, print PDFs, test-print PDFs, full-size previews and original manual. Print at **100% / Actual Size** and check the **50 × 50 mm** square on the test sheet. The artwork includes **3 mm of bleed**.

## Variants

| Series | Variants |
|---|---|
| Canada US | A and B with the revised gold spine logos |
| Canada EU · German PAL | A and B |
| Canada EU · English PAL | A and B |
| EU Classic | German PAL and English PAL |
| US Classic | Original N64 and N64 Collector Edition |

In the Canada designs, A adds a light shimmer to the forest artwork. B uses the forest artwork without the added shimmer.
